# 📝 도움 메모

아이들 태블릿에 **지금 할 일**이 메모지처럼 뜨고, 막히면 **🙋 도와주세요**를 눌러 선생님께 알리는 웹앱이에요.
안드로이드, iPad, PC 브라우저 어디서나 돼요. 앱을 설치할 필요가 없어요.

- `teacher.html`: 선생님 현황판. 방 번호, 도움 요청 목록, 반 아이들 상태, 단계 편집
- `index.html`: 아이들 메모지. 방 번호와 이름을 쓰고 들어가요 (`index.html?room=1234` 주소로 들어오면 방 번호가 자동으로 채워져요)

## 수업 흐름
1. 선생님이 `teacher.html`을 열면 방 번호가 생겨요. 오른쪽에 오늘 할 단계를 써요.
2. 아이들은 학생 주소로 들어와 이름을 써요.
3. 선생님이 ◀ ▶ 또는 단계 번호를 누르면 아이들 메모지가 바로 바뀌어요.
4. 아이가 **다 했어요**를 누르면 초록색, **도와주세요**를 누르면 빨간색으로 표시되고 띵 소리가 나요. 도와준 다음 **해결했어요**를 누르면 돼요.
5. 다음 수업 전에 **학생 목록 비우기**를 눌러요.

## 연습 모드와 실제 사용
`config.js`가 비어 있으면 **연습 모드**예요. 이 컴퓨터의 브라우저 탭끼리만 연결돼요.
아이들 태블릿과 연결하려면 무료 Firebase를 한 번 설정해야 해요. [설정방법.md](설정방법.md)를 보세요.
